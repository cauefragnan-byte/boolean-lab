Por que AND?

O operador && só retorna true quando todas as condições são verdadeiras. Se o e-mail ou a senha estiver incorreto, o resultado será false e o acesso será negado.

O CÓDIGO REAL

A função usada neste login

01

Comparação estrita

O JavaScript compara o que foi digitado com os valores esperados usando ===. Cada comparação produz true ou false.

02

Operação booleana

Em seguida, usuarioCorreto && senhaCorreta combina os dois resultados com o operador AND.

03

Tomada de decisão

O if usa o resultado final. Se for verdadeiro, esta página é aberta; se for falso, o formulário exibe um aviso.
